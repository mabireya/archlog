# 🎯 ArchLog (아크로그)

**초·중등부 학생선수 양궁 연간 성과 관리 웹앱**

1년간의 학생선수 대회 일정, 선수 명단, 거리별·종별 경기 성과를 한눈에 파악하고 관리할 수 있는 단일 파일 기반 웹 애플리케이션입니다. 별도 서버나 설치 없이 브라우저만으로 바로 사용할 수 있으며, 엑셀(CSV) 내보내기와 학교 공식 결재란이 포함된 가로형 A4 보고서 인쇄를 지원합니다.

---

## ✨ 주요 기능

### 1. 한눈에 보기 (대시보드 & 연간 매트릭스)
- **8대 핵심 KPI 카드**: 등록 대회 수, 등록 선수 수, 총 출전 기록, 1위(금)·2위(은)·3위(동)·장려/입선 집계, PB 달성 건수를 실시간으로 집계합니다.
- **학생선수별 입상 현황 그래프**: Chart.js 기반 스택 막대 그래프로 선수별 누적 입상 현황을 비교합니다.
- **선수 × 연간 대회명 매트릭스 표**: 빈 칸을 클릭하면 해당 선수와 대회가 자동 선택되어 즉시 성과를 기입할 수 있고, 기존 기록을 클릭하면 바로 수정됩니다.

### 2. 5대 조건 실시간 필터 & 정밀 검색
- **부별**: 초등부 / 중등부
- **종별**: 리커브 / 컴파운드
- **대회규모**: 전국대회 / 도대회 / 시군대회 / 교내대회 / 기타
- **등수별**: 전체 입상 / 메달권(1~3위) / 1위(금) / 2위(은) / 3위(동) / 장려·입선 / 본선진출 / 참가
- **거리별**: 공식 거리 및 단체전·개인종합·실내 18m별 필터링
- **⚡ PB만 보기** 토글 및 통합 키워드 검색 지원

### 3. 초·중등부 공식 양궁 거리 자동 연동
성과 기록 시 학생선수를 선택하면 해당 선수의 부별과 주종목에 맞는 대한양궁협회 공식 거리 버튼이 자동으로 표시됩니다.

| 부별 | 종별 | 공식 거리 및 부문 |
| :--- | :--- | :--- |
| **초등부** | 리커브 | `20m`, `25m`, `30m`, `35m`, 개인종합, 단체전, 혼성단체, 실내 18m |
| **초등부** | 컴파운드 | `20m`, `30m`, 개인종합, 단체전, 혼성단체, 실내 18m |
| **중등부** | 리커브 | `30m`, `40m`, `50m`, `60m`, 개인종합, 단체전, 혼성단체, 실내 18m |
| **중등부** | 컴파운드 | `30m`, `50m`, 개인종합, 단체전, 혼성단체, 실내 18m |

### 4. 원클릭 퀵 액션 & 보고서 출력
- 어느 탭에서나 상단의 **`+ 대회 추가`**, **`+ 선수 추가`**, **`+ 성과 기록`** 버튼으로 즉시 기입할 수 있습니다.
- **엑셀 호환 CSV 내보내기 (UTF-8 BOM)**: 상세 성과 전체 / 연간 매트릭스 표 / 현재 검색 결과 3종을 한글 깨짐 없이 엑셀로 저장합니다.
- **가로형 A4 공식 보고서 인쇄**: 상단 결재란(담당·부장·교감·교장)이 포함된 인쇄 전용 레이아웃을 제공합니다.

## 💾 데이터 저장 안내

- 입력한 모든 데이터는 사용 중인 기기의 브라우저(`localStorage`)에 자동 저장됩니다.
- **주의**: 다른 PC나 스마트폰에서는 데이터가 자동 동기화되지 않으며, 브라우저 캐시·사이트 데이터를 삭제하면 기록이 초기화될 수 있습니다.
- 중요한 대회 기록을 입력한 뒤에는 상단의 **엑셀 CSV 내보내기**로 주기적으로 백업해 두는 것을 권장합니다.

## 🚀 GitHub Pages로 나만의 주소 만들기

1. 이 저장소에 웹앱 파일을 **`index.html`** 이름으로 업로드합니다.
2. 저장소 상단 **`Settings`** → 좌측 **`Pages`** 메뉴로 이동합니다.
3. **Branch**를 `main`, 폴더를 `/ (root)`로 선택한 뒤 **`Save`**를 클릭합니다.
4. 1~2분 뒤 상단에 생성된 `https://[아이디].github.io/archlog/` 주소로 접속해 바로 사용할 수 있습니다.
